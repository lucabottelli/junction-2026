Sort into the good and defect plates

Once the decision at WP2 is made, the rest is a fixed move: carry the brick to the right plate, let go, go back to the start pose. No learning needed, just two more taught waypoints.

How it will work

  1. Decision at WP2 (phase 3) picks the destination.
  2. Scripted carry from WP2 to the good plate or the defect plate, with the gripper command locked at the value it had at the hand-off, so the clamp force never changes on the way.
  3. Release above the plate, rise, and return to the start pose for the next brick.

Why scripted

The plates never move, so the path is the same every time. Replaying taught waypoints with smooth, speed-limited motion is faster and more repeatable than a learned move, and it keeps the policy's capacity for the one part that varies: the pick.
