Pick a specific block among several

The first ACT model learns to pick whatever block is on the plate. The next step is choosing: “pick up the pink one”, with the other blocks lying around as distractors. ACT is already a vision policy (top + wrist images and joints in, actions out). What it needs next to it is something that decides which block and checks the right one ended up in the gripper.

How it will work

  1. Block finder on the top camera. A colour segmentation, or a small detector if colour isn't enough, finds every block on the orange plate and returns the target's position.
  2. Option A: one ACT per block. Export one dataset per block (the export can already select “pink only”) and let the finder choose which model runs.
  3. Option B: one language-conditioned policy. SmolVLA trained on the same data, prompted with “pick up the pink brick”. Every episode already stores that task text per frame.
  4. Check the grasp. After the hand-off the finder confirms the right block is in the gripper before the carry continues.

Why the data already fits

Recording is organised per block: round 1 is the block alone (30–50 episodes in every position and orientation), round 2 has the other blocks lying around as distractors (20–30 episodes). Both options train on exactly those episodes, so nothing has to be re-recorded.

Stretch

Robot-generated demonstrations: the robot sets the block down at a known random pose and records the pick back, so the dataset grows without a human at the leader.
